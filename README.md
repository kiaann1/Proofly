# Proofly

Proofly is a modern platform for logging work, compiling achievements, and building ATS-optimized CVs—ideal for freelancers, creatives, and anyone who needs proof-of-work.

## Features

- Manual task logging (summary, attachments, highlights)
- CV/portfolio builder with templated export
- Built-in ATS (Applicant Tracking System) compatibility checker
- Intuitive UI with reminders and search
- Future: integrations with cloud tools for automated logging

## Tech Stack

- Next.js (React)
- TypeScript
- TailwindCSS (UI)
- [Prisma ORM (DB)](https://www.prisma.io/) (optional, for persistent storage)
- PostgreSQL or SQLite (for development)

## Getting Started

1. `npm install`
2. `npm run dev`
3. Visit [http://localhost:3000](http://localhost:3000)
